# 零基础入门

欢迎！这篇指南用**大白话**介绍 ShadowQUIC，不需要任何网络背景知识。
如果你从来没接触过代理工具，从这里开始最合适。

ShadowQUIC 是一个运行在**两台机器**上的代理工具：

- 一台 **服务器**：放在远程（你有控制权 / 有公网 IP 的机器上）
- 一台 **客户端**：放在你本地（笔记本、手机、路由器）

它构建了一条快速且难以被封锁的隧道。由于隧道从外部看起来与普通加密网页流量无异，防火墙很难区分它与正常网站访问。
